# Ejemplos de Versionado

## Patch

Subir de `5.7.0` a `5.7.1`

Usar cuando:
- se corrige un texto roto
- se ajusta un modal
- se arregla un calculo puntual sin cambiar la arquitectura

## Minor

Subir de `5.7.0` a `5.8.0`

Usar cuando:
- se agrega una funcion nueva
- se incorpora historial salarial
- se agrega auditoria o una vista nueva

## Major

Subir de `5.7.0` a `6.0.0`

Usar cuando:
- cambia la estructura principal del sistema
- cambia el modelo de datos de forma incompatible
- cambia el flujo base de liquidacion o autenticacion
