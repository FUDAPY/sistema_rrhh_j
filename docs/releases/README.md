# Releases

Esta carpeta concentra la estructura operativa para mantener un historial sano desde este punto en adelante.

## Archivos

- `RELEASE_CHECKLIST.md`
  - Lista de control antes de publicar una nueva version
- `RELEASE_NOTES_TEMPLATE.md`
  - Plantilla para documentar cada release
- `VERSIONING_EXAMPLES.md`
  - Ejemplos practicos para decidir si un cambio es major, minor o patch
